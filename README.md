# Pooha Choi — Personal Website

Academic portfolio for Pooreunhaneul (Pooha) Choi, an undergraduate
mathematics student at KAIST.

The site is intentionally dependency-free: open `index.html` directly or serve
the repository with any static file server.

## Content

- About
- Research interests
- English and Korean CV links
- Academic contact

## Deployment

This repository is structured for GitHub Pages deployment from the `main`
branch.
